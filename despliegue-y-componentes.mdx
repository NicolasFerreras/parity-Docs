# Diagrama de Despliegue — Parity

> Visualización de cómo se conectan los componentes del sistema en producción y desarrollo local.

## Producción (Nube)

```mermaid
flowchart TB
    subgraph USUARIO["👤 Usuario"]
        BROWSER["🌐 Browser"]
    end

    subgraph GITHUB["GitHub"]
        REPOS["Repositorios<br/>(backend-go + frontend-react)"]
        ACTIONS["GitHub Actions<br/>CI/CD"]
    end

    subgraph FRONTEND["Frontend — Cloudflare Pages"]
        SPA["React + TypeScript<br/>SPA (:443)"]
    end

    subgraph BACKEND["Backend — Render"]
        API["Go API Server<br/>(:8080)"]
        WORKERS["Workers Go<br/>(async jobs)"]
    end

    subgraph SUPABASE["Supabase Cloud"]
        PG["PostgreSQL<br/>(:5432)"]
        AUTH["Supabase Auth<br/>(JWT validation)"]
        STORAGE["Storage<br/>(archivos Excel/PDF)"]
    end

    subgraph EXTERNAL["Servicios Externos"]
        SENTRY["Sentry<br/>(errores)"]

    end

    %% Conexiones
    BROWSER -->|"HTTPS"| SPA
    SPA -->|"API REST HTTP"| API

    API -->|"SQL queries"| PG
    API -->|"JWT validation"| AUTH
    API -->|"upload/download files"| STORAGE
    API -->|"capture errors"| SENTRY
    API -->|"send emails"| RESEND

    WORKERS -->|"process async jobs"| PG
    WORKERS -->|"LLM processing"| PG

    REPOS -->|"push to main"| ACTIONS
    ACTIONS -->|"deploy backend"| API
    ACTIONS -->|"deploy frontend"| SPA
    ACTIONS -->|"goose up (migraciones)"| PG

    CRON -->|"ping cada 14 min"| API

    %% Estilos
    classDef frontend fill:#61dafb,stroke:#333,color:#000
```

## Leyenda

| Componente | Servicio | Función |
| --- | --- | --- |
| **Cloudflare Pages** | Frontend hosting | Sirve la SPA React, CDN global |
| **Render** | Backend hosting | Ejecuta la API Go + workers async |
| **Supabase Cloud** | DB + Auth + Storage | PostgreSQL, autenticación JWT, archivos |
| **Sentry** | Error tracking | Captura y reporta errores del backend |
| **Resend** | Email transaccional | Emails de bienvenida, notificaciones |
| **cron-job.org** | Keep-alive | Ping `/healthz` cada 14 min (proyecto free) |
| **GitHub Actions** | CI/CD | Tests + deploy automático al mergear a main |
