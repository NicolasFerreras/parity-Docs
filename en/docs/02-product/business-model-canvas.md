# Business Model

| Block | Definition |
| --- | --- |
| **Segment** | Distributors with 1,000–10,000 SKUs and multiple clients with heterogeneous formats. |
| **Proposition** | Standardize orders in seconds without changing systems. |
| **Channels** | Direct sales, demos with client catalog. |
| **Relationship** | Operational support and initial catalog setup. |
| **Revenue** | Subscription by order volume or active catalogs. |
| **Key Resources** | Go + PostgreSQL platform, React interface, catalog and matching engine. |
| **Key Activities** | Validation, matching and review — focused on reliability. |
| **Partners** | Docker infrastructure, documentation hosting. |
| **Costs** | Development, infrastructure and support. |

Parity grows with the client: more catalogs and orders without rework.
