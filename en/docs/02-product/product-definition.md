# Product Definition

Parity is a platform that turns messy orders into structured, validated data in seconds.

## Problem

Sales teams receive orders in different formats per client —Excel with variable columns, PDF, copied text— and must retype them to match the internal code, barcode and quantity format. That retyping consumes time, introduces errors and delays invoicing.

## Solution

Parity reads the file as it arrives, crosses it with the catalog and presents a table where each line is classified as exact, ambiguous or failed. The user corrects only what needs attention and exports.

## Principle

Technology assists, the person decides. Parity never guesses an ambiguous product: it flags it for review.
