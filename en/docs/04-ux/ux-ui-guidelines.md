# UX/UI Guidelines

Parity prioritizes clarity and control. The interface does not replace the user's judgment: it assists.

## Principles

* **Single table:** everything is reviewed and corrected in one place, without changing screens.
* **Visible states:** each line shows `exact / ambiguous / failed` with color and text.
* **Immediate editing:** inline correction, no unnecessary modals.
* **One click to export:** when everything is green, export is immediate.

## Tone

Direct, operational, no jargon. Each message explains what happened and what to do next.
