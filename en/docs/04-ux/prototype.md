# Prototype

The prototype validates the flow without waiting for external integrations.

## What You Can Test

* Upload a real Excel with 20–100 lines and see classification in seconds.
* Search the catalog by code or barcode to resolve ambiguous.
* Edit a failed line and see it turn exact.
* Export and open the resulting file in Excel.

## What It Does Not Include

* Login or multi-user.
* Order history or analytics.
* Automatic ERP integration.

Prototype is in `src/features/orders` and `src/features/matching` — ready for demos with client catalog.
