# Modelo de negocio

| Bloque | Definición |
| --- | --- |
| **Segmento** | Distribuidoras con catálogos de 1.000–10.000 SKUs y múltiples clientes con formatos heterogéneos. |
| **Propuesta** | Estandarizar pedidos en segundos sin cambiar de sistema. |
| **Canales** | Venta directa, demos con catálogo del cliente. |
| **Relación** | Soporte operativo y configuración inicial de catálogo. |
| **Ingresos** | Suscripción por volumen de pedidos o catálogos activos. |
| **Recursos clave** | Plataforma Go + PostgreSQL, interfaz React, catálogo y motor de matching. |
| **Actividades clave** | Validación, matching y revisión — con foco en confiabilidad. |
| **Socios** | Infraestructura Docker, hosting de documentación. |
| **Costos** | Desarrollo, infraestructura y soporte. |

Parity crece con el cliente: más catálogos y pedidos sin re-trabajo.
