# Definición de producto

Parity es una plataforma que convierte pedidos desordenados en datos estructurados y validados en segundos.

## Problema

Los equipos de ventas reciben pedidos en formatos distintos por cliente —Excel con columnas variables, PDF, texto copiado— y deben reescribirlos manualmente para que cumplan el formato interno de código, barras y cantidades. Ese re-tipeo consume tiempo, introduce errores y retrasa la facturación.

## Solución

Parity lee el archivo tal como llega, lo cruza con el catálogo y presenta una tabla donde cada línea está clasificada como exacta, ambigua o fallida. El usuario corrige solo lo que necesita atención y exporta.

## Principio

La tecnología asiste, la persona decide. Parity nunca adivina un producto ambiguo: lo señala para revisión.
