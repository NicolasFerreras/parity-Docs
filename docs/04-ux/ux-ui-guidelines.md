# Guías UX/UI

Parity prioriza claridad y control. La interfaz no reemplaza el criterio del usuario: lo asiste.

## Principios

* **Una sola tabla:** todo se revisa y corrige en el mismo lugar, sin cambiar de pantalla.
* **Estados visibles:** cada línea muestra `exacta / ambigua / fallida` con color y texto.
* **Edición inmediata:** corrección inline, sin modales innecesarios.
* **Un clic para exportar:** cuando todo está en verde, la exportación es inmediata.

## Tono

Directo, operativo, sin jerga. Cada mensaje explica qué pasó y qué hacer a continuación.
